# FlipPhone-SubMenu-App
Most android-based flip phones (e.g. Kyocera DuraXV Series, DuraXA series, etc. ) have a 3x3 app launcher in their home screen app with multiple sub-menus that can be changed. This is a custom 3x3 grid sub menu to replace the default one. This is based off of the custom tcl flip2 submenu developed by apps4flip devs, and can be navigated via the keypad.
